# 테마 배경 문양

AI Hub `한국 전통 문양 데이터`의 카테고리별 문양 유형과 상징 정보를 참고해
오매루트용으로 새로 그린 반복형 SVG 배경입니다. AI Hub 원본 이미지나 가공 이미지를
복사·포함하지 않습니다.

| 파일 | 참고한 유형·상징 | 적용 테마 |
| --- | --- | --- |
| `food-pattern.svg` | 기하문 · 조화와 균형 | 광주 미식 |
| `heritage-pattern.svg` | 문자문 · 연결과 조화 | 역사·전통 |
| `culture-pattern.svg` | 기하문 · 조화와 질서 | 문화·예술 |
| `nature-pattern.svg` | 동물문 · 풍요와 번영 | 자연·경관 |
| `garden-pattern.svg` | 동물문 · 행운과 장수 | 공원·정원 |
| `activity-pattern.svg` | 동물문 · 장수와 번영 | 체험·스포츠 |
| `walk-pattern.svg` | 식물문 · 청정함과 고귀함 | 도보·산책 |

앱은 로컬 AI Hub 원본 유무와 관계없이 이 폴더의 SVG를 사용하므로 모든 PC에서 같은
스탬프 배경이 표시됩니다.

# 테마 스탬프 자산

오매루트 스탬프판에서 사용하는 편집 가능한 최종 SVG 자산입니다.

| 파일 | 적용 테마 |
| --- | --- |
| `food.svg` | 음식점·구장 먹거리 전체 |
| `heritage.svg` | 역사·전통 |
| `culture.svg` | 문화·예술 |
| `nature.svg` | 자연·경관 |
| `garden.svg` | 공원·정원 |
| `activity.svg` | 체험·스포츠 |
| `walk.svg` | 도보·산책 |

SVG는 Figma·Illustrator·Inkscape 또는 텍스트 편집기로 수정할 수 있습니다. 파일명과
`viewBox="0 0 120 100"`을 유지하면 앱 코드를 바꾸지 않고 디자인만 교체할 수 있습니다.

이 파일들은 AI Hub 원본 문양 이미지가 아니라 오매루트용으로 직접 제작한 벡터 도안입니다.
AI Hub 원본 및 로컬 가공 이미지는 저장소에 포함하지 않습니다.

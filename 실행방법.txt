오매루트 공유용 코드 실행 방법
================================

[Windows에서 가장 간단하게 실행]
1. ZIP 파일을 원하는 폴더에 완전히 압축 해제합니다.
2. 압축을 푼 폴더에서 "서버실행.bat"를 더블클릭합니다.
3. 서버 창을 닫지 않은 상태로 기다리면 브라우저에서 아래 주소가 열립니다.

   http://localhost:4173/

4. 사용을 마치면 "Omaeroute Server" 창을 닫습니다.

※ Windows 실행에는 Python 설치가 필요하지 않습니다.
   Windows에 기본 포함된 PowerShell로 정적 서버를 실행합니다.


[Windows에서 명령어로 실행]
1. 압축을 푼 프로젝트 폴더를 엽니다.
2. 폴더 빈 곳에서 Shift + 마우스 오른쪽 버튼을 누르고
   "터미널에서 열기" 또는 "PowerShell 창 열기"를 선택합니다.
3. 아래 명령을 실행합니다.

   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start_server.ps1

4. 브라우저에서 http://localhost:4173/ 에 접속합니다.
5. 종료할 때 서버 창에서 Ctrl + C를 누릅니다.


[macOS / Linux에서 실행]
1. 터미널을 열고 압축을 푼 폴더로 이동합니다.
2. Python 3가 설치되어 있다면 아래 명령을 실행합니다.

   python3 -m http.server 4173

3. 브라우저에서 http://localhost:4173/ 에 접속합니다.
4. 종료할 때 터미널에서 Control + C를 누릅니다.


[중요]
- index.html을 직접 더블클릭하지 마세요.
  브라우저 보안 정책 때문에 장소·음식점 JSON 데이터가 로드되지 않을 수 있습니다.
- 반드시 ZIP을 먼저 완전히 압축 해제한 뒤 서버를 실행하세요.
- 서버 명령은 index.html, app.js, data 폴더가 보이는 프로젝트 최상위 폴더에서 실행해야 합니다.


[문제 해결]
- 배치 파일을 눌렀는데 바로 닫히는 경우:
  위의 "Windows에서 명령어로 실행" 명령을 사용하면 오류 내용을 확인할 수 있습니다.
- "Port 4173 is already in use"가 나오는 경우:
  이전에 실행한 서버 창을 닫고 서버실행.bat를 다시 실행하세요.
- 데이터가 계속 로딩 중인 경우:
  브라우저 주소가 file:///가 아니라 http://localhost:4173/인지 확인하세요.
- 카카오맵 인증 오류가 나는 경우:
  Kakao Developers의 JavaScript SDK 도메인에 http://localhost:4173이 등록되어 있는지,
  config.js에 REST API 키가 아닌 JavaScript 키가 입력되어 있는지 확인하세요.


[주요 시연 흐름]
1. 시작하기
2. 출발 장소·출발일·귀가일·시간 입력
3. 여행 취향 설정
4. 스포츠·야구 매우 선호 시 야구 직관 선택
5. 맞춤 루트 생성
6. 지도·추천 일정·구장 음식 메뉴 확인
7. 스탬프·리뷰·시연용 리워드 및 루트 저장 확인
